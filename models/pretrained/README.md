# Pretrained Models

Place official YOLO pretrained weights here when running training locally.

Suggested examples:

- `yolov8n.pt`
- `yolov8m.pt`
- `yolo11n.pt`

The actual `.pt` files are intentionally ignored by Git because they are large
binary artifacts. If a specific release needs fixed weights, publish them as
GitHub Release assets and reference the download URL in the release notes.
